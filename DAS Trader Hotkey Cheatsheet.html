Command Tip

Command Tip

Command Tip


This is to set the order price to previous close price
Price=AvgCost
Command Tip


This is to set the order price to the average cost of the position which is implied by current selected symbol and account in montage window.
Price=Round2
Command Tip


This is to round the order price to specified number of decimals to avoid too many decimals which could lead to order being rejected. Currently Round1, Round2, Round3 and Round4 are supported, which correspond to 1, 2, 3 and 4 decimals. For example, if original price is 25.238, after executing hotkey "Price=Round2", new price will be 25.24.
FPrice=price
Command Tip


This hotkey will set the value of the price text box that is on focus. For example, if Stop Trigger Price text box is on focus, then this hotkey will enter the "price" value specified in the hotkey script into the text box. There are 3 price text boxes on Montage window that can be set using this hotkey.
Price=share
Command Tip


This hotkey will set the value of the price text box with the value of Share text box operated with a number (or no number). For example, price=share*100 will set price to 100 multiplied by number of shares in Share text box.
Price=RoundNearestMultiple
Command Tip


Format is RoundNearestMultipleNum. Then price will be rounded to a number which is Num divided by 100. For example, RoundNearestMultiple25 will round order price to nearest multiple of 0.25, RoundNearestMultiple300 will round to nearest multiple of 3.

Share

ScriptTip
Share=Pos
Command Tip


This will set the number of shares to the amount you already own (as shown in the Positions window) for the relevant symbol.
Share=Share+0
Command Tip


This will increase/decrease the number of shares displayed in Shares box of the selected Trading window. Change 0 to the number of shares you want to increase.
Use Share=Share-0 to decrease.
Share=DEFSHARE+0
Command Tip


This will set the number of shares higher or lower than the default number of shares by a specified amount. Change 0 to the amount of increment of decrement.
Use Share=DEFSHARE-0 for decrement.
Share=0
Command Tip


This will set the number of shares to a specified number. Change 0 to that specified amount.
Share=1000/Price
Command Tip


This is to set the number of shares to a specified number which is the rounding result of an integer number divided by the value of Price. The value of Price is the price text box in Montage window.
Share=Pos*0.5
Command Tip


This is to set shares using percentage. "Pos" can be replaced by an integer or "Share" depending on user's strategy.
Share=BP*0.5
Command Tip


For buy order. Please note that this hotkey will actually execute Share=BP*0.5/Price. It will set the number of shares to the rounding value of buying power multiplied by a percentage (0.5 in this example) divided by Price. For a limit order, the value of Price is the value in price text box; For a market order, the value of Price is the last price or bid price. For example, current account's buying power is 10,000, the price value is 20 in price text box, so number of shares will be set to 10,000*0.5/20=250.
Share=BPS*0.5
Command Tip


Same with Share=BP*0.5, but for short order.
Share=ROUND
Command Tip


If share value less than 100, this script will round it to 100.
FShare=share
Command Tip


This hotkey will set the value of the qty (number of shares) text box that is on focus. Currently two qty text boxes on Montage window can be set. When this hotkey is pressed, the box that is on focus will be set to the value specified in "share" in the script.
Share=LOCATED
Command Tip


Set available locate shares.
Share=1000/StopPrice
Command Tip


This is to set the number of shares to a specified number which is the rounding result of an integer number divided by the value of StopPrice. The value of StopPrice is the stop price text box in Montage window.

          Command Tip
         

        
        

        Send primary order and trigger order.
        

        Example:
        

        ROUTE=LIMIT;Price=Ask+0.1;Share=100;TIF=DAY+;WithTrigger=ACT:SELL QTY:100 RT:STOP StopType:Market StopPrice:Bid-0.05 TIF:DAY;BUY/SELL
        

        Last BUY/SELL command is for primary order.
        

        Each field's definition:
        

        
         RT
        
        : route, ARCAL/ARCAM/STOP etc.;
        

        
         StopType
        
        : LIMIT/MARKET/Trailing/Range;
        

        
         PX
        
        : order's price. STOPPRICE: order's stop price.
        

        
         ACT
        
        : SELL/BUY/SHORT;
        

        
         QTY
        
        : order's shares, can be a digit value or 'POS';
        

        
         TIF
        
        : time in force, DAY+/DAY/IOC etc.;
        

        
         ACC
        
        : account for this trader, default is primary order's account;
        

        
         SYM
        
        : order's symbol, default is primary order's symbol;

AUTOCXLCOVER

         

          Command Tip
         

        
        

        

        Toggle the Auto Cancel Cover order; When the AutoCancelCover is ON, the order will be marked as auto cancel.  This order will be canceled when the position is liquidated but only IF the order that liquidated the position was also marked as ON.  For example, customer is long 500 shares of ABC.  Customer then posts a sell order through INET and another sell order through ARCA, both marked as Auto Cancel.  As soon as the position goes flat, the Order Server will automatically cancel the remaining open sell orders marked ON, but only IF the order that flattened the position was also marked as ON.  If it was marked as OFF those orders will still remain active.

          Command Tip
         

        
        

        

        Set the Auto Cancel Cover order ON; When the AutoCancelCover is ON, the order will be marked as auto cancel.  This order will be canceled when the position is liquidated but only IF the order that liquidated the position was also marked as ON.  For example, customer is long 500 shares of ABC.  Customer then posts a sell order through INET and another sell order through ARCA, both marked as Auto Cancel.  As soon as the position goes flat, the Order Server will automatically cancel the remaining open sell orders marked ON, but only IF the order that flattened the position was also marked as ON.  If it was marked as OFF those orders will still remain active.

          Command Tip
         

        
        

        

        Set the Auto Cancel Cover order OFF; When the AutoCancelCover is ON, the order will be marked as auto cancel.  This order will be canceled when the position is liquidated but only IF the order that liquidated the position was also marked as ON.  For example, customer is long 500 shares of ABC.  Customer then posts a sell order through INET and another sell order through ARCA, both marked as Auto Cancel.
